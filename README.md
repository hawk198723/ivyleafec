# Ivy Leaf Education Center

React website rebuild for Ivy Leaf Education Center.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Tour request form

The homepage form submits to `info@ivyleafec.com` using FormSubmit. When the site is first deployed, FormSubmit may send a one-time activation email to that inbox. Approve it so future form submissions are delivered normally.
